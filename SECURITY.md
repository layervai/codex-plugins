# Security Policy

## Reporting a vulnerability

Do not report security vulnerabilities or include access links, private keys,
or other secrets in public issues.

Use [GitHub private vulnerability reporting](https://github.com/layervai/codex-plugins/security/advisories/new)
or email [security@layerv.ai](mailto:security@layerv.ai).

Include the affected plugin version, steps to reproduce, and potential impact.

## Supported versions

Security fixes apply to the latest plugin version. Update the marketplace with
`codex plugin marketplace upgrade layerv` and update the installed plugin before
retesting a reported problem.
